# Política de seguridad / Security Policy

Este es un fork no oficial basado en Evolution API v2.3.7. Se ofrece tal cual ("AS IS"), sin compromiso de soporte ni plazos de respuesta garantizados.

## Reportar una vulnerabilidad

Por favor, **no abras un issue público** para reportar vulnerabilidades de seguridad.

### Canales preferidos

1. **GitHub Private Vulnerability Reporting:** utiliza la pestaña **Security -> Advisories -> Report a vulnerability** de este repositorio para enviar un aviso privado.
2. **Correo electrónico:** escribe a **jaimefernando3112@gmail.com** con el asunto `[SECURITY] evoapi-resilient - <descripción breve>`.

### Qué incluir
- Descripción clara de la vulnerabilidad y pasos para reproducirla.
- Impacto estimado y versión/commit afectado.
- **No incluyas** claves reales (`apikey`), tokens, credenciales ni números reales de teléfono.

Si la vulnerabilidad afecta al código base original de Evolution API, repórtala también al proyecto upstream según su política (`suporte@evofoundation.com.br`).
