# Contribuir / Contributing

Este es un fork no oficial compartido tal cual ("AS IS") sin compromiso de mantenimiento o soporte.

Si deseas reportar un fallo o proponer una mejora:
1. Verifica que sea reproducible en esta copia limpia (`npm run build` y `npm run test:regressions`).
2. No incluyas credenciales, tokens, números reales de teléfono ni datos de clientes en reportes o parches.
3. Si el problema corresponde al proyecto original, considera reportarlo también en [evolution-foundation/evolution-api](https://github.com/evolution-foundation/evolution-api).
